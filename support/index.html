Support

Speakeasy lets you call your own Hermes agent: ask for a few things, keep talking while it works, and hear when each one is done.

What you need

  • A Hermes agent with the Speakeasy plugin installed. Ask your agent: “Install Speakeasy for me: speakeasyvoice.ai/setup.md”.
  • A voice service on that Hermes: a ChatGPT sign-in, or an OpenAI API key.
  • Tailscale on both your Hermes computer and this device, signed in to the same account, if Hermes runs on another machine.

No Hermes yet? Tap Try a sample call on the app's first screen to see how a call works. Nothing connects and the mic stays off.

Pairing

  1. Ask your Hermes agent: “Pair my iPhone with Speakeasy.”
  2. Tap the link it sends you. The app opens and pairs.
  3. Or copy the link, open Speakeasy, and paste it in.

Pairing links include a one-time 6-digit code that expires. If one doesn't work, ask Hermes for a new one.

Common problems

  • The app can't reach your Hermes. Check that Tailscale is on, on both devices, with the same account. Then use Test connection under Settings.
  • The call connects but nobody answers. The voice service on your Hermes may need you to sign in again. Ask your agent to check Speakeasy's voice setup.
  • The app says a plugin update is available. Tap Copy the request for Hermes in Settings and send it to your agent. Restart Hermes when it asks.
  • Starting a call without opening the app. Add the Speakeasy widget or the Start Speakeasy control, set the Action Button to Talk to Speakeasy, or say “Hey Siri, talk to Speakeasy.”

Get help

  • Email support@speakeasyvoice.ai.
  • Report a bug or ask for a feature on GitHub.
  • Testing the beta? Take a screenshot in the app and send it as TestFlight feedback.
